# Semantic HTML5 & Accessible Component Architecture

## Project Overview

This project demonstrates the implementation of a semantic HTML5 and accessible enterprise dashboard.

The project follows semantic HTML5 standards and accessibility best practices based on WCAG 2.1 guidelines.

The main objective is to create a structured, accessible and keyboard-friendly dashboard using semantic HTML elements.

---

## Website / Project

Project Type: Accessible Enterprise Dashboard

Technologies Used:

- HTML5
- CSS3
- JavaScript
- Semantic HTML
- Accessibility / WCAG 2.1
- Keyboard Navigation
- W3C HTML Validation

---

## Objectives

The main objectives of this project are:

1. Create an accessible multi-page dashboard.
2. Use proper semantic HTML5 elements.
3. Implement accessible navigation.
4. Provide keyboard-only navigation support.
5. Create accessible forms with proper labels.
6. Implement an accessible modal dialog.
7. Use proper heading hierarchy.
8. Validate the HTML using the W3C Nu HTML Checker.
9. Maintain a clean and organized repository structure.

---

## Semantic HTML5 Elements Used

The project uses semantic HTML5 elements such as:

- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<aside>`
- `<footer>`
- `<form>`
- `<fieldset>`
- `<legend>`
- `<label>`
- `<table>`
- `<dialog>`

These elements provide a meaningful document structure and improve accessibility for screen-reader and keyboard users.
