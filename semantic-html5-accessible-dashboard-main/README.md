# Semantic HTML5 & Accessible Component Architecture

## Project Overview

This project demonstrates a semantic HTML5 and accessible enterprise dashboard architecture following WCAG 2.1 accessibility principles.

The project focuses on semantic HTML structure, keyboard accessibility, accessible forms, data sections, navigation, footer and modal dialogs.
